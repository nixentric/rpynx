## The missing text: Ren'Py 8.5.3 resets the game's gui values

The buttons all use `size gui.main_menu_button_font_size`:
- the game declares `define gui.main_menu_button_font_size = 0`;
- then it sets it to 40 in `init python`.

Ren'Py 8.5.3's `change_language()` calls `gui._apply_rebuild()`, which runs
`renpy.ast.redefine(["store.gui"])`. That re-runs every `define gui.*` statement, so the
value goes back to 0, while the `init python` block does not run again. Ren'Py 7.5.3 did not
do this on a language change, only in `gui.rebuild()`. 8.5.3's `00compat.rpy` has no switch
for it. Ren'Py also calls `change_language(force=True)` at start-up, so the reset happens
even before the player picks a language.

The desktop repro, `tests/integration/renpy_desktop/compat.sh` (synthetic game,
`script_version` 7.5.3), shows `gui.btn` as 0 with plain 8.5.3, and 40 through our bridge.
