## Causes and fixes (runtime `5748c070…`, not yet run on a Switch)

- **Missing font.** The Question's preferences screen draws its language buttons in
  `SourceHanSansLite.ttf`.
  - Its `options.rpy:166` adds `config.renpy_base + "/sdk-fonts"` to the search path, where the
    SDK keeps that font, and sets `build._sdk_fonts = True`.
  - With that flag set, the SDK's distribute tool copies the font into `game/`. So a game
    built with the SDK has the font, and one copied straight from the SDK folder does not.
  - `runtime/renpy/build.sh` now stages the SDK's `sdk-fonts` (both SIL OFL 1.1, 2.9 MB) into
    `renpy-base/sdk-fonts`, which is `config.renpy_base` on the Switch.
- **Load log.** The after-load callback only sets a flag. The bridge prints the line at the
  next interaction, when the loaded statement is current.
