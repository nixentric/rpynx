## Root causes

1. **importlib has its own `_path_isabs`.** Since 3.12, `spec_from_file_location` and
   `FileFinder` make paths absolute with it. The posixpath patch (0005) did not cover it,
   so `romfs:/…` was treated as relative and the working directory was prepended.
2. **`poll()` hangs on Horizon** without the BSD socket service. `selectors` probes it at
   import time, and `socket`, `subprocess` and `asyncio` all import `selectors`.

## Fixes for run 4 (runtime sha256 `44a6de7a…72d2`, uploaded and read back over FTP)

- CPython patch `0006-importlib-horizon-device-paths.diff`: on Horizon, `_path_isabs` treats
  `device:/` as absolute. Covered by `tests/unit/test_horizon_paths.py` (31 checks); the
  decoded frozen module contains the change.
- `config.site`: `ac_cv_func_poll=no`, so `select.poll` is absent and `selectors` uses
  `select()`. Confirmed: `HAVE_POLL` is undefined.
