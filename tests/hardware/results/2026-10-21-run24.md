## Causes and fixes (runtime `24c65402…`, not yet run on a Switch)

- **D-pad skip.** Ren'Py's `focus_nearest` only moves "down" to a button whose box starts
  at or below the bottom edge of the selected one (`focus.py:961`). Forbidden Fantasy's
  buttons are taller than their spacing, so the boxes overlap and Continue is never a
  candidate.
  - The bridge also accepts a box that overlaps but whose centre is clearly further in
    that direction (more than a quarter of the height or width), in all four directions.
  - Ren'Py's distance still chooses the nearest candidate.
  - Desktop: the compat game `stacked` reproduces the skip without the fix (it picks
    Supporter Content) and picks Continue with it.
- **Links and folders.** `renpy.open_url`, `webbrowser.open*` and `subprocess.Popen` of
  `xdg-open`/`open`/`explorer`/`start` now show a notice:
  - for a website: its address, to open on a phone or computer;
  - for a folder or file: its path;
  - an OK button, which is selected.

  Other `Popen` calls behave as before. Desktop: the compat game `links` passes (notice
  shown, OK selected, OK closes it).
- **Error exit.** Both error paths (game error, thread still running) now use the system
  error dialog (`errorApplicationShow`) instead of the libnx console.
