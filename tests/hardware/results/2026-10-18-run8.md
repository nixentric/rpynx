## Symbolised from the fatal screen

Offsets are PC/LR/backtrace minus the start address `0x6D693DF000`, resolved with `addr2line`
on `dist/renpy-runtime.elf` of the same build:

```
PC   0x17f26c0  memcpy
LR   0xc65e58   u_default_buffer_subdata         (Mesa)
BT00 0xc1390c   st_bufferobj_data                (Mesa)
BT01 0xb7ecbc   buffer_data_error                (Mesa glBufferData)
BT02 0x2ba6ec   GLTexture.load_gltexture         (Ren'Py gl2texture)
BT05 0x2aff80   GLTexture.load                   (Ren'Py gl2texture)
```

Ren'Py was uploading an image to the GPU, and Mesa's `glBufferData` path crashed in its
`memcpy` into the buffer. [Likely] the buffer allocation failed for lack of memory and Mesa
does not check for that. Applet mode gets only a fraction of the memory application mode
gets (3189 MiB in run 1). A crash inside a system applet is fatal for the whole console.
